## 📸 Test Media Uploads

### Add a Dog
1. Tap "Add Dog" button
2. **Take photo** or select from gallery
3. Fill in details
4. Save

✅ Photo uploads to Supabase Storage!

### Create Report
1. Tap "Report" tab
2. Select report type
3. **Upload photo**
4. Add description
5. Submit

✅ Image/PDF uploads to Supabase Storage!

### Log Feeding
1. Find a dog on map
2. Tap "Log Feed"
3. **Take photo** of feeding
4. Submit

✅ Photo uploads to Supabase Storage!
